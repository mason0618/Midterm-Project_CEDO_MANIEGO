Tasks for the Management System

A CodeIgniter 4 web application with task management, authentication, customer management, staff management, products, inventory, and sales recording.

Features

Staff login and logout
Hashed passwords and session authentication
Authentication filter for protected pages
Public homepage and task list
Full task CRUD with soft deletion
Task validation for title and date
Customer create, edit, view, and delete
Staff create, edit, view, and delete
Hashed passwords for staff accounts
Product CRUD
Product price and stock tracking
JPG and PNG product image uploads
New sale recording
Stock validation before completing a sale
Automatic stock deduction after a sale
Sales history with customer, staff, total, and date
CSRF-protected forms
Validated form inputs and file uploads
Escaped output in views
Database migration, seeder, and SQL export files
Technologies Used

CodeIgniter 4
PHP 8.2 or higher
MySQL
HTML and CSS
